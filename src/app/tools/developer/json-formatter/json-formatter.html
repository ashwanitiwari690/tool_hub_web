JavaScript Object Notation (JSON) is an open-standard, lightweight, text-based data interchange format defined by RFC 8259. It is universally used across modern software engineering for REST API communication, configuration files (such as tsconfig.json or package.json), and NoSQL document storage (like MongoDB).

JSON represents data hierarchically using two core structures:

  • Objects: Key-value collections wrapped in curly braces ({}), where keys are double-quoted strings.
  • Arrays: Ordered lists of values enclosed in square brackets ([]).

Production web servers and microservices transmit JSON in "minified" format—stripping all line breaks and spaces to reduce HTTP payload size. However, minified JSON is virtually unreadable for developers debugging API errors. Formatting (pretty-printing) restores indentation and hierarchical structure so engineers can instantly inspect object nesting, verify data types, and spot malformed payloads.

ToolNova leverages the browser's native JavaScript engine:

  • Parsing: The raw text is passed to JSON.parse(). If any syntactic anomaly exists (such as a missing quote or trailing comma), the engine throws a syntax error with line and character position details.
  • Formatting: The parsed JavaScript object is converted back to string format using JSON.stringify(parsed, null, 2), which injects two-space indentation at every nesting depth.
  • Minification: Executing JSON.stringify(parsed) without indentation strips all non-essential whitespace, creating a compact single-line string.

  • Strict JSON vs. JavaScript Objects: Standard JSON does not permit comments (// or /* */), single-quoted strings ('key'), unquoted keys, or undefined values.
  • 64-bit Integer Precision: Numbers exceeding Number.MAX_SAFE_INTEGER (9,007,199,254,740,991) may experience precision loss during standard IEEE 754 JavaScript parsing unless passed as strings.
  • Circular References: JSON does not support self-referential or circular object trees.
  • Trailing Commas: Placing a comma after the final item in an object or array (e.g., {{"{\"a\": 1, \"b\": 2,}"}}) causes an immediate syntax error. Remove the trailing comma.
  • Single Quotes: Replace all single quotes (') with standard double quotes (").
  • Unquoted Keys: Ensure every object key is enclosed in double quotes (e.g., "username": "alex" instead of username: "alex").
