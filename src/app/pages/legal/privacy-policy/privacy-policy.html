1. Client-Side Tool Processing (Zero Server Upload)

The core philosophy of {{ siteConfig.name }} is local-first execution. Our interactive tools — including the Word Counter, Case Converter, JSON Formatter, JSON Validator, Image Compressor, Image Resizer, QR Code Generator, Percentage Calculator, Age Calculator, and Unit Converter — execute entirely inside your web browser using standard client-side JavaScript, the HTML5 Canvas API, and Web APIs.

  • Your data stays on your device: Text typed or pasted into text or developer tools is processed in volatile browser memory and is never transmitted to, stored on, or analyzed by our servers.
  • No file uploads: Images selected for compression or resizing are loaded directly into your browser's local memory and transformed via the Canvas API. At no point are your image files sent across the network to our infrastructure.
  • No account or login required: You can access and utilize all tools anonymously without creating an account, registering an email address, or submitting personal identifiers.

2. Browser Storage (Cookies & LocalStorage)

To provide a seamless user experience, {{ siteConfig.name }} utilizes standard browser web storage technologies:

  • Local Storage: We use your browser's localStorage solely to save your local UI preferences across sessions. This includes:
    • toolnova:theme — stores your preferred visual theme (light, dark, or system).
    • toolnova:favorites — keeps track of your favorited tools for quick access.
    • toolnova:recent-tools — lists your recently opened tools in the navigation overlay.
    This data never leaves your browser and can be cleared at any time through your browser settings.
  • Cookies: While {{ siteConfig.name }} does not set first-party tracking cookies for basic site functionality, third-party partners (such as Google AdSense) may set cookies as described below. For full details, please read our Cookie Policy.
